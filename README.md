# Chess AI Assignment

This project implements a simple Chess AI that plays full games using two different algorithms: **Minimax** and **Alpha-Beta Pruning**. The games are visualized using Pygame and recorded as MP4 videos.

##  Features

- AI agents using:
  - Minimax algorithm
  - Alpha-Beta Pruning (optimized Minimax)
- Basic board evaluation function using piece values and game termination detection.
- Visual chess board rendering using SVG-to-PNG conversion.
- Game playback visualization using Pygame.
- Gameplay recording using OpenCV and saved as video.
- Video and slides are uploaded seperately in github repo
